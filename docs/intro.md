# Gitsaurus

Gitsaurus is a practical Git and GitHub guide for software development projects.

Use this site when you need to:

- set up a repository
- work with your team
- create branches
- commit and push code
- open and review Pull Requests
- protect your repository
- fix common Git problems

## Not Sure Where to Start?

### 🚀 Setting up a project?

Go to [Create a Repository](./setup/create-repository.md).

### 🔁 Starting work for the day?

Go to [Get the Latest Team Code](./workflow/pull.md).

### 👥 Working with teammates?

Go to [Create a Pull Request](./workflow/pull-requests.md).

### 🚨 Something went wrong?

Go to [Before You Panic](./troubleshooting/intro.md).

:::tip[One important habit]

When you are unsure what Git thinks is happening, start with:

```bash
git status
```

:::
