# `git status`

Use:

```bash
git status
```

to see the current state of your working directory and staging area.

It can tell you:

- your current branch
- whether your branch is ahead or behind
- modified files
- staged files
- untracked files
- whether a merge is in progress

## When Should I Use It?

Frequently.

Especially:

- before pulling
- before committing
- before switching branches
- when something goes wrong

:::tip

If you are confused about what Git is doing, `git status` should usually be your first command.

:::
