# Fork a Repository

A **fork** creates another GitHub repository based on an existing GitHub repository.

Think of it as:

```text
Original GitHub Repository
          ↓
         Fork
          ↓
Your GitHub Repository
```

A fork happens on GitHub.

A clone downloads a repository to your computer.

```text
Fork  = GitHub → GitHub
Clone = GitHub → Your computer
```

## Step 1: Open the Original Repository

Open the GitHub repository you want to fork.

## Step 2: Click Fork

Click **Fork** near the top-right of the repository.

## Step 3: Choose the Owner

Select where the fork should be created.

#### For course projects, this may be your course organization.

## Step 4: Choose the Repository Name

Use the required naming convention for your course or team.

## Step 5: Create the Fork

Click **Create fork**.

Your new repository is connected to the original repository.

## For Team Projects

If your team is supposed to share one repository, only create **one team fork**.

Your workflow should look like:

```text
Instructor / Starter Repository
             ↓
          Team Fork
             ↓
      Team members clone
        the same fork
```

Not:

```text
Starter Repository
   ↓---------↓---------↓
Student A Student B Student C
  fork      fork      fork
```

unless your assignment specifically requires individual forks.
